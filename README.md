Information Systems student at **Universitas Pelita Harapan** based in Tangerang, Indonesia. I like building things for the web — from small static sites to full-stack applications with databases and authentication.

I spend most of my time on front-end work, but I'm happiest when a project has a real backend behind it: scheduling systems, dashboards, and anything that needs persistence.
